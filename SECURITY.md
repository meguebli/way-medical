# Security Policy

## Signalement

Ne pas publier une vulnerabilite dans une issue publique.

Utiliser un canal prive defini par l'organisation pour remonter:

- faille de securite
- exposition de donnees
- mauvaise gestion des permissions
- fuite de secrets

## Regles minimales

- Aucun secret dans Git
- Donnees de sante interdites dans le repository
- Principe du moindre privilege
- Journalisation sans donnees sensibles
- Revue de securite obligatoire pour auth, permissions, stockage et API exposees
