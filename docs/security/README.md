# Security Notes

## Base line

- Secrets via coffre fort ou variables d'environnement gerees
- MFA sur les comptes de la forge et du cloud
- Protection de branche activee
- Revue obligatoire sur zones sensibles
- Dependabot ou equivalent active
- Secret scanning active

## Medical / sensitive data

- Ne pas utiliser de vraies donnees patients en dev
- Preferer des jeux de donnees synthetiques
- Limiter les acces aux environnements
- Tracer les acces aux donnees sensibles
